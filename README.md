# VELVET — MVP

Премиальный демонстрационный каталог массажа 18+ для Волгограда и Волжского.

## Локальный запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000.

Стартовая версия использует вымышленные анкеты и иллюстрации. Контактов и бронирования нет. До публичного запуска необходима юридическая проверка и модерация.
